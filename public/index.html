02 — Questions & answers

A platform.
Clear boundaries.

What the current foundation does, what the architecture proposes and what still needs evidence.

What is Eylema?

Eylema is a platform in development for defining, running and evolving cooperative agentic loops. Stable role contracts connect local participants, Rust execution, decision evidence and permitted training data. The deterministic task console is its first implemented foundation.

Architecture v0.5
What works today?

The public core includes typed Rust tasks, deterministic execution, durable recovery, a local loopback service, CLI and browser console. The console creates tasks, runs deterministic actions and inspects persisted state. Verified-human stop authorization remains a separate acceptance requirement. This promotional site does not run the console or establish full-product acceptance.

Implemented console and limits
Can I swap models or use XState now?

The architecture proposes compatible model replacement and a local XState workflow adapter. These integrations are not yet accepted runtime features. MiniCPM, Qwen and decision policies require exact supported profiles; arbitrary weights are not interchangeable. Rust remains responsible for authority and execution truth.

Roles, model replacement and XState
How are decisions explained?

The proposed evidence record links goals, source observations, alternatives, constraints, model versions, validation and observed outcomes. A readable summary must reference that evidence. Hidden model reasoning is not proof; predictions and suggestions remain distinct from observed facts.

Decision evidence design
Does running a loop permit training on my data?

No. Collection and training need their own purpose, permission, retention and export policy. The proposed dataset builder keeps episode lineage and related samples in the same split, including failures and corrections. Unsloth is an external training tool; no accepted training or model-improvement result is claimed.

Data permissions and learning
Which platform comes first?

The first experimental target is a single-user loopback application on a MacBook Pro with Apple M4 Pro and 24 GB unified memory. Browser and native execution have distinct boundaries. Mac mini M4 and Linux RTX equipment are additional inventory, not accepted support; remote access and Linux acceptance are future scope.

Accepted scope and hardware inventory
What is the project license?

Eylema first-party core code and documentation use Apache-2.0. Separately identified third-party material, model weights and datasets retain their own terms. This does not grant a blanket license to every asset or model, or change the website repository license.
