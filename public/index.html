02 — Questions & answers

A clear idea.
An honest start.

The essential facts about Eylema, with the original design documents one click away.

What is Eylema?

Eylema is a proposed agentic AI web platform for continuous development and operations. Its design connects explicit application contracts, AI development teams and local agents, with human-defined authority.

Architecture v0.3
Can I use Eylema today?

You can explore the public architecture, API and team protocol drafts. There is no released Eylema framework, production API, supported model runtime or published performance benchmark yet. This website introduces the design; it is not a platform demo.

Current project status
Who stays in control?

The design keeps people in command of goals, authority, budgets and delegation. Humans can participate at required approval points, inspect outcomes and request intervention. Models cannot expand their own permissions. These oversight mechanisms still require implementation and testing.

API and human oversight
Where will Eylema run?

The proposed targets are Rust/Wasm in the browser with WebGPU, and native Rust execution on Linux. Browser, operating system, drivers and model artifacts remain explicit dependencies. Device compatibility and combined performance have not yet been validated.
